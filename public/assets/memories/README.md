# Event photos

Place event images here, then edit the matching entry in src/data/places.ts:

```ts
reflection: "Bruce’s own notes about this event.",
photos: [
  { src: "/assets/memories/summerhacks.jpg", alt: "Describe the actual photo", caption: "Optional caption" },
],
```

Omit these fields until real photos and notes are available. Multiple photos are supported. Never substitute another person's event photos for Bruce's memories.
